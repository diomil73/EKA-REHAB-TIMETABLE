# Guided replacement workflow

This workflow joins three existing pieces into one user action:

1. Rank feasible replacement providers using the confirmed load-first policy.
2. Let the operator choose a ranked provider by number.
3. Apply that provider's recommended feasible timeslot to a new patient-centric Excel preview.

The source workbook remains read-only. The workflow writes only to a preview copy.

Current scope: therapists from workbook SETTINGS. Real named students will join the same workflow after the student registry is connected to workbook data.
