# Replacement timeslot rules

A provider is not rejected merely because the patient's original time is occupied.

The operational ranking remains:

1. lower current daily workload;
2. exact-time availability;
3. another common free timeslot for both patient and provider.

For a provider who needs a time change, the UI may show all feasible times. The default recommended alternative is the free slot closest to the original/requested time, while the user remains free to choose another feasible slot.

This is a recommendation layer only. The patient-centric conflict checks remain authoritative before an assignment is committed.
