Rehab Center System - Native Excel write-back foundation

This patch does NOT write to the baseline workbook.
It adds:
- rich-text write plans for line-level strike-through
- DailyExcelRenderPlan -> safe WritePlan conversion
- Windows Excel COM writer that writes only to a new .xlsm copy
- source SHA-256 guard
- cleanup of partial output on failure
- runtime probe for Windows + Excel + pywin32

Test result in development environment: 131 passed.
Actual Microsoft Excel COM execution must be verified on the user's Windows PC.
