Patient-centric assignment + automatic SlotGroup patch

- derived SlotGroup model based on independent patient assignments
- automatic pair/group formation for same therapist + same time
- weekday overlap detection instead of silently accepting same-day collisions
- pure reassignment helper proving one pair member can move independently
- documentation for shared-cell daily behaviour
- durable project documentation for intranet hyperlinks, progress charts, therapist dashboards and multi-user operation

No Excel write-back is changed by this patch.
